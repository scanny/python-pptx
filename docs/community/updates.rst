Software Updates
================

Project status (2026)
---------------------

**python-pptx is actively maintained** on the ``loadfix/python-pptx``
fork. Upstream ``scanny/python-pptx`` issues are triaged and addressed
in this fork — the capability catalogue in ``FEATURES.md`` records
300+ audited-issue resolutions layered on top of upstream ``1.0.2``,
spanning slide duplication and cross-deck merging, animations and
transitions, sections, modern chart types, shape effects,
password-protected saves, slide comments, math equations, SmartArt
scaffolding, custom document properties, slide-level tags, and
accessibility alt text.

If you've landed here from the upstream repository looking for a
maintained path forward, start at:

- `issue tracker <https://github.com/loadfix/python-pptx/issues>`_ —
  file fork issues here; upstream's tracker is for upstream-shared
  concerns only
- ``FEATURES.md`` in the repository root — single-page catalogue of
  every public capability, with fork-era additions marked
  ``[Added in <version>.dev0]``
- ``HISTORY.rst`` (reproduced below) — the user-visible changelog
